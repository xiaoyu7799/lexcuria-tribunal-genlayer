# LexCuria

GenLayer on-chain multi-party adjudication and precedent evolution protocol.

- Status: draft stage. Gemini is designing the contract and frontend; nothing here is deployed or verified yet.
- Network: GenLayer Stable Studionet only, chain ID 61999. Zero cash cost, no real funds.
- Direction (Gemini handover, 2026-11-03): Subjective Adjudication — validators independently read unstructured evidence, reach a discrete-bps verdict (PASS 10000 / PARTIAL 2500 / 5000 / 7500 / REJECT 0), the contract settles nominal escrow, updates credibility scores, and appends the case to an on-chain precedent corpus. Interaction: four-act courtroom stage, not hero + form + vault.
- This repo will be filled by the Muse deployment/verification pass once the Gemini draft is handed over. Do not treat any draft claim as deployed or FINALIZED until Muse verifies it on Studionet.
